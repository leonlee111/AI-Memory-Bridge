# 🧠 AI Memory Bridge v2.3.2

**跨平台 AI 对话记忆管理插件** — 在 Gemini、DeepSeek、Claude、ChatGPT、Kimi、通义千问 等 AI 平台之间，轻松抓取、保存、管理和注入你的指令与 AI 回复。

---

## 📋 功能总览

| 功能 | 说明 |
|------|------|
| 🔍 **智能扫描** | 一键识别页面中所有用户指令 + AI 回复，带角色标注 |
| 📎 **文件提取** | 识别对话中的附件/文件卡片，并尽量合并到对应指令或回复内容 |
| 💾 **记忆库** | 保存、搜索、筛选、置顶、编辑、批量删除 |
| 📁 **项目组** | 将相关指令分组管理，支持合并、重命名、批量注入 |
| 📤 **一键注入** | 将保存的指令直接填入 AI 输入框 |
| 📄 **导出笔记** | 将项目组导出为独立 HTML 笔记文件（可编辑、自动保存） |
| 🤖 **AI 笔记** | 接入 AI API 自动将对话整理为结构化笔记 |
| 🔄 **数据迁移** | JSON 导出/导入，跨浏览器/跨设备迁移记忆 |
| 🖥️ **页面内面板** | 在 AI 页面直接操作，无需打开弹出窗口 |

## ✨ 功能详解

### 🔍 智能扫描引擎

在 AI 对话页面点击悬浮按钮 🧠 → 🔍 扫描，插件会自动识别页面中的所有对话内容：

- **用户指令** 👤 — 你发送给 AI 的问题和指令
- **AI 回复** 🤖 — AI 的回答内容
- **对话文件** 📎 — 页面中可见的附件卡片、文件链接、图片/文档资源
- **四层扫描策略**：
  1. `data-*` 属性（最可靠，ChatGPT/Claude 标准属性）
  2. 平台专属 CSS 选择器
  3. 语义化 class 名称
  4. class 关键词兜底
- **智能去重**：Map 以 DOM 元素为 key，避免同一内容被多个选择器重复抓取
- **祖先过滤**：父容器和子节点都命中时，丢弃父容器保留更精确的内层节点
- **AI 回复合并**：同一 AI 回复被拆成多个 DOM 片段时，自动合并为一条完整内容
- **DeepSeek 特殊处理**：过滤思考过程（thinking/reasoning 块），避免被误识别为用户指令
- **平台前缀清理**：自动去除 AI 回复开头的 "Gemini说"、"DeepSeek：" 等平台标签
- **滚动检测**：滚动到底部时自动检测并补充新内容
- **文件合并**：识别到的文件会优先合并进对应的用户指令或 AI 回复；只有页面完全没有对话内容时，才会作为独立文件条目保存

### 📎 文件提取

文件提取会扫描对话 DOM 中可见的附件信息，包括文件名、类型、大小、链接等。点击页面浮窗中的「🔍」会同时扫描对话和文件；点击「扫文件」可以单独补扫页面附件。

- **不强行下载私有文件**：插件只记录页面可见的文件元数据和可访问链接，不绕过 AI 平台权限读取私有文件。
- **内容内合并**：文件信息会写入记忆内容末尾的「相关文件」区域，同时保留结构化 `attachments` 字段，便于导出和 AI 笔记整理。
- **导出联动**：普通 HTML 笔记会展示“相关文件”，AI 辅助笔记会把附件信息一起发给模型整理。

### 💾 记忆库管理

- **保存**：单条保存、多条批量保存、保存为项目组
- **标签分类**：通用、编程、写作、分析、自定义
- **搜索筛选**：按关键词搜索 + 按标签筛选
- **置顶**：重要记忆置顶，优先显示
- **编辑**：修改标题、内容、标签
- **批量删除**：点击「☑ 批量」→ 勾选要删除的记忆 → 「🗑 删除选中」
- **使用统计**：记录每条记忆的注入次数

### 📁 项目组管理

将相关的指令和回复组织成项目组：

- **创建**：扫描后选择「保存为项目组」
- **操作**：重命名、删除、合并多个项目组
- **批量注入**：一键将项目组所有指令合并注入到输入框
- **导出笔记**：将项目组导出为独立 HTML 笔记文件

### 📄 导出笔记网页

将项目组内容导出为 Microsoft Learn 风格的独立 HTML 文件：

| 特性 | 说明 |
|------|------|
| **标题提取** | 优先用用户提问前 52 字作标题，无提问则取 AI 回答摘要 |
| **智能去重** | 关键词重叠 ≥40% 的问答对只保留最新的 |
| **文本清理** | 自动去除 emoji、"当然！好的！" 等夸张词汇 |
| **左侧目录** | 粘性侧边栏目录，滚动时自动高亮当前章节 |
| **响应式** | 移动端自适应布局 |
| **蓝绿标签** | 蓝色「提问」/ 绿色「回答」徽章清晰区分双方 |
| **自动保存** | 笔记内容修改后自动保存到 localStorage |

**触发位置**：
- AI 页面浮动面板 → 项目组标签 → 📄 导出笔记
- 插件 Popup → 项目组 → 📄 导出笔记（任意页面可用）

### 🤖 AI 辅助生成笔记

配置 AI API Key 后，可将项目组中的对话自动整理为结构化笔记：

1. 在设置中填入 API Key、API 地址、模型名称
2. 在项目组中点击「🤖 AI 笔记」
3. AI 自动将问答对整理为带标题层级、代码块的 HTML 笔记
4. 浏览器自动下载笔记文件

### 📤 一键注入

- **单条注入**：记忆库 → 点击「📤 注入」，自动填入当前 AI 页面的输入框
- **批量注入**：项目组 → 「📤 全部注入」，所有指令合并后填入
- **智能适配**：支持 contenteditable（如 Gemini）和 textarea（如 DeepSeek）
- **兜底方案**：非 AI 平台自动切换为复制到剪贴板

### 🖥️ 页面内浮动面板

在 AI 页面直接操作，无需打开弹出窗口：

- **悬浮按钮** 🧠：可拖拽到任意位置，显示记忆数量角标
- **三个标签页**：扫描结果 / 记忆库 / 项目组
- **扫描结果**：勾选要保存的条目，支持全选/取消
- **记忆库**：搜索、筛选、注入、复制、置顶、删除
- **项目组**：全部注入、导出笔记、AI 笔记、重命名、删除

### 🔄 数据导入/导出

- **导出**：将所有记忆和项目组导出为 JSON 文件
- **导入**：从 JSON 文件导入记忆和项目组（追加模式，不会覆盖已有数据）
- **用途**：跨浏览器迁移、备份、分享给其他设备

## 🚀 快速开始

### 安装

1. 下载本项目文件夹 `ai-memory-plugin/`
2. 打开 Chrome 浏览器 → 地址栏输入 `chrome://extensions/`
3. 开启右上角 **「开发者模式」**
4. 点击 **「加载已解压的扩展程序」**
5. 选择 `ai-memory-plugin/` 文件夹

### 基本使用

```
1. 打开任意支持的 AI 平台（Gemini / DeepSeek / Claude / ChatGPT / Kimi / 通义千问）
2. 点击页面右下角紫色悬浮按钮 🧠 打开面板
3. 点击 🔍 扫描当前页面所有指令、回复和文件
4. 勾选要保存的条目，点击 💾 保存
5. 选择保存方式：单条 / 多条 / 项目组
```

### 注入指令到输入框

```
方式一：记忆库 → 点击「📤 注入」
方式二：项目组 → 「📤 全部注入」
方式三：快速注入 Tab → 选择记忆 → 注入
```

### 导出笔记

```
1. 扫描并保存为「项目组」
2. 面板切到「项目组」标签 → 点击「📄 导出笔记」
3. 浏览器自动下载 .html 文件
4. 用任意浏览器打开即可查阅
```

## 🛒 商店上架

当前版本已完成 Chrome Web Store / Microsoft Edge Add-ons 上架前准备：

- `manifest.json` 已升级到 Manifest V3，版本号 `2.3.2`
- 已去除远程 Google Fonts 依赖，减少商店审核风险
- 商店上传包建议命名为 `AI-Memory-Bridge-v2.3.2-store.zip`
- ZIP 包内 `manifest.json` 必须位于根目录，可直接上传到 Chrome/Edge 开发者后台

本地打包命令：

```powershell
if (!(Test-Path .\dist)) { New-Item -ItemType Directory .\dist | Out-Null }
$items = Get-ChildItem -LiteralPath .\ai-memory-plugin -Force
Compress-Archive -LiteralPath $items.FullName -DestinationPath .\dist\AI-Memory-Bridge-v2.3.2-store.zip -Force
```

上架仍需要开发者账号后台人工操作：

1. Chrome Web Store：登录 Chrome Web Store Developer Dashboard，上传 ZIP，填写详情、隐私字段、权限说明、测试说明后提交审核。
2. Microsoft Edge Add-ons：登录 Partner Center，创建新扩展，上传 ZIP，填写可用市场、隐私信息、商店详情和认证测试说明后提交。

权限说明建议：插件需要读取支持的 AI 页面以扫描对话；需要 `storage` 保存本地记忆；需要 `clipboardWrite` 支持复制/兜底注入；需要网络权限访问用户配置的 OpenAI 兼容 API 端点以生成 AI 笔记。

## 🔧 技术架构

- **Chrome Extension Manifest V3**
- **数据存储**：`chrome.storage.local`（最大 5MB，约可存储 500 条记忆）
- **扫描引擎**：Map-based DOM 去重 + 祖先过滤 + 优先级角色分类
- **异常防护**：`safeMsg()` 封装所有 `chrome.runtime.sendMessage`，防止插件热重载后崩溃
- **平台适配**：每个平台独立配置选择器，互不干扰

## ❓ 常见问题

**Q: 插件更新后提示「插件已更新，请刷新页面」？**
A: 刷新当前页面即可恢复使用。这是因为 Chrome 扩展热更新导致 content script 上下文失效。

**Q: 扫描结果不完整？**
A: 尝试滚动到页面底部触发加载更多内容，然后再次点击扫描。

**Q: 注入按钮无效？**
A: 插件会自动检测输入框，如果找不到合适的输入框会改为复制到剪贴板。

**Q: 如何迁移数据到另一台电脑？**
A: 在旧电脑点击「📤 导出」→ 将 JSON 文件传到新电脑 → 安装插件 → 点击「📥 导入」。

**Q: 记忆库最多能存多少条？**
A: `chrome.storage.local` 限制为 5MB，约可存储 500 条记忆。超出时会自动丢弃最旧的记忆。
