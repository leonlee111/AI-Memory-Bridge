# 🧠 AI Memory Bridge v2.1

跨平台 AI 指令记忆管理插件，支持用户指令与AI回复全量识别、滚动抓取、项目组管理、**一键导出笔记网页**。

## ✨ 功能特性

### 🔍 智能扫描（v2.0 重写）
- **用户指令 + AI回复** 全量识别，带 👤/🤖 角色标注
- **四层扫描策略**：data属性(最可靠) → 平台专属选择器 → 语义标签 → class关键词兜底
- **DOM去重**：以元素为key的 Map，避免同一内容被多个选择器重复抓取
- **祖先过滤**：若父容器和子节点都命中，丢弃父容器只保留内层更精确的节点
- **DeepSeek修复**：将同父节点下3+个同角色兄弟节点合并为父节点，避免一条回复被拆成多条
- **优先级角色**：低优先级选择器不能覆盖高优先级已确定的角色标注
- **滚动识别**：滚动到底部时自动检测并补充新内容

### 📦 项目组管理
- **自动分组**：同一次扫描的指令可保存为一个项目组
- **重命名 / 删除 / 合并**
- **批量注入**：一键注入项目组所有指令到输入框
- **📄 导出笔记网页**（v2.1 新功能）

### 📄 导出笔记网页（v2.1 新增）
将项目组内容导出为 Microsoft Learn 风格的独立 HTML 笔记文件：

| 特性 | 说明 |
|------|------|
| **标题提取** | 优先用用户提问前52字作标题，无提问则取AI回答摘要 |
| **智能去重** | 关键词重叠 ≥40% 的问答对只保留最新的，丢弃旧的 |
| **文本清理** | 自动去除 emoji、"当然！好的！非常好的问题" 等夸张词汇 |
| **左侧目录** | 粘性侧边栏目录，滚动时自动高亮当前章节 |
| **响应式** | 移动端自适应布局 |
| **蓝绿标签** | 蓝色「提问」/ 绿色「回答」徽章清晰区分双方 |

**触发位置**：
- AI 页面浮动面板 → 项目组标签 → 📄 导出笔记
- 插件 Popup → 项目组 → 📄 导出笔记（任意页面可用）

### 💾 记忆库
- 保存单条/多条/整个项目组的指令
- 标签分类（通用、编程、写作、分析、自定义）
- 搜索筛选 / 置顶 / 使用统计
- **批量删除**：点击「☑ 批量」进入批量选择模式，可全选/取消/批量删除多条记忆

### 📤 快速注入
- 一键注入：直接填入 AI 输入框（contenteditable / textarea 均支持）
- 非 AI 平台自动切换为复制到剪贴板
- 批量注入：项目组全部指令合并注入

### 🔄 数据管理
- JSON 格式导出/导入，包含项目组数据
- 一键清空

## 🚀 使用说明

### 基本使用
1. 打开任意支持的 AI 平台（Gemini、DeepSeek、Claude、ChatGPT、Kimi、通义千问）
2. 点击页面右下角紫色悬浮按钮 🧠 打开面板
3. 点击 🔍 扫描当前页面所有指令和回复
4. 勾选要保存的条目（👤 用户指令 / 🤖 AI回复），点击 💾 保存
5. 选择保存方式：单条 / 多条 / 项目组

### 导出笔记网页
1. 在 AI 平台扫描并保存为**项目组**
2. 面板切到「项目组」标签，点击 **📄 导出笔记**
3. 浏览器自动下载 `项目组名_笔记.html`
4. 用任意浏览器打开即可查阅，无需网络

### 注入指令
- 单条注入：记忆库 → 点击「注入」
- 批量注入：项目组 → 「📤 全部注入」

### 快捷操作
- 悬浮按钮可拖拽到任意位置
- 插件更新后若出现「⚠️ 插件已更新」提示，刷新页面即可恢复

## 🔧 技术说明

- **Chrome Extension Manifest V3**
- **数据存储**：`chrome.storage.local`（最大 5MB）
- **扫描引擎**：Map-based DOM 去重 + 祖先过滤 + 优先级角色分类
- **异常防护**：`safeMsg()` 封装所有 `chrome.runtime.sendMessage`，防止插件重载后的 `Extension context invalidated` 崩溃
